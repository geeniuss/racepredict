# RacePredict

Web3-powered F1 prediction market built on Avalanche, featuring open order book, on-chain treasury & point system, and modern F1-themed UI.

**Monorepo Structure:**
- `contracts/`: Solidity smart contracts
- `backend/`: Node.js + TypeScript REST API server
- `frontend/`: React + Vite frontend
- `shared/`: Shared types and schemas

_Built step by step, copy-pasteable for your GitHub workflow._
